# OutreachPro – BDA Outreach & Follow-up Tracker

OutreachPro is a Flask-based Business Development Associate CRM designed to manage prospects, outreach activities, follow-ups, meetings and sales opportunities.

## Features
- Prospect and company management
- Lead source and sales-stage tracking
- Follow-up date management
- Outreach activity history: calls, emails, WhatsApp, meetings and demos
- Pipeline value calculation
- Conversion-rate dashboard
- Search and filter prospects
- Prospect detail and activity timeline
- SQLite database
- Responsive professional dashboard

## Tech Stack
- Python
- Flask
- SQLite
- HTML/CSS
- Jinja2

## Run locally

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`
